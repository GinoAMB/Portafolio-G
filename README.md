## 💻 Instalación

```bash
git clone https://github.com/GinoAMB/portafolio-G.git
cd portafolio
npm install
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:5173
```

### Build

```bash
npm run build
npm run preview
```
