## ✨ Sobre el proyecto

Este portafolio fue diseñado como una presentación profesional de mi perfil y experiencia en desarrollo web.

El objetivo es mostrar de forma clara:

* 👤 Perfil profesional
* 💼 Experiencia
* 🚀 Proyectos destacados
* 🛠️ Tecnologías y herramientas
* 📄 Currículum
* 📬 Información de contacto

El diseño busca mantener una estética **minimalista, moderna y orientada al desarrollo de software**, con una interfaz responsive para dispositivos móviles, tablets y escritorio.

## 📂 Estructura del proyecto

```text
src/
├── assets/
├── components/
│   ├── layout/
│   │   └── Navbar.tsx
│   └── ui/
├── sections/
│   ├── hero/
│   ├── about/
│   ├── experience/
│   ├── projects/
│   ├── stack/
│   └── contact/
├── App.tsx
├── index.css
└── main.tsx
```

La estructura está organizada por **secciones y componentes reutilizables**, facilitando el mantenimiento y crecimiento del proyecto.
